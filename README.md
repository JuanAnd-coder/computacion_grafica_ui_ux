## 📱 Proyecto Destacado: App de Finanzas Personales

Prototipo de interfaz web interactiva diseñado para el seguimiento, control y gestión de la economía personal diaria. El diseño se enfoca en la usabilidad, claridad visual y estructuración semántica de la información financiera.

### 📂 Estructura del Proyecto

```text
finanzas-personales/
├── css/                  # Estilos, maquetación y reglas responsivas
├── img/                  # Recursos visuales e iconografía
├── index.html            # Vista principal y panel general (Dashboard)
├── ingresos.html         # Módulo de registro y flujo de entradas
├── gastos.html           # Control y desglose detallado de egresos
└── reportes.html         # Resumen analítico y balance financiero
```

### 🌟 Características Clave

* **Dashboard Intuitivo:** Vista general rápida de saldos, movimientos recientes y resúmenes.
* **Gestión de Ingresos y Gastos:** Módulos independientes para categorizar cada flujo monetario.
* **Módulo de Reportes:** Estructura preparada para la visualización gráfica de balances y métricas.
* **Diseño Responsivo:** Adaptabilidad para dispositivos móviles, tablets y escritorios.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semántico:** Uso de etiquetas estándares (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) para optimizar el acceso y estructura.
* **CSS3:**
  * Layouts modernos (**Flexbox** & **CSS Grid**) para la distribución del contenido.
  * Diseños adaptativos mediante *Media Queries*.
  * Estilizado personalizado, variables CSS y transiciones fluidas.

## 🚀 Instalación y Ejecución Local

Para visualizar y probar la interfaz en tu computadora:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/JuanAnd-coder/COMPUTACION_GRAFICA.git
   ```
2. **Navegar a la carpeta del proyecto:**
   ```bash
   cd COMPUTACION_GRAFICA
   ```
3. **Abrir en el navegador:**
   Abre el archivo `index.html` en tu navegador preferido o utilízalo con la extensión **Live Server** en Visual Studio Code.
