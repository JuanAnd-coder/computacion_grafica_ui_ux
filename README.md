# Computación Gráfica & UI/UX

Este repositorio reúne proyectos de maquetación web desarrollados con HTML5 y CSS3.

## 📱 Proyecto Destacado: App de Finanzas Personales
Prototipo de interfaz web interactiva para el seguimiento y gestión de ingresos/gastos diarios.

* **Estructura:**
  * `index.html` / `inicio.html`: Vista principal del panel general.
  * `ingresos.html`: Módulo de registro de entradas financieras.
  * `gastos.html`: Control detallado de egresos.
  * `reportes.html`: Visualización y balance financiero.

## 🛠️ Tecnologías Utilizadas
* HTML5 semántico
* CSS3 (Diseño responsivo / Layouts)
